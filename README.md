# 电商经营核对 Skill

固定四表 Excel 核对 MVP：上传订单、退款、平台费用和成本，生成可逐单追溯的经营报表。

- 仅支持一种输入格式：固定四表 v1，币种 CNY，一行一订单。
- 检查字段缺失、重复编号、无法关联的记录和金额异常。
- 使用 Decimal 解析金额，再用整数分计算；不使用 AI 猜测金额，不自动补零或去重。
- 输出 Excel 经营汇总、订单明细、异常清单和计算说明，并保留原始文件、行号与 SHA-256。
- 50 组模拟 Excel 场景及两份演示输出已验证。

## 运行条件

当前版本面向 Windows 上的 Codex 本地环境，需要：

- Python 3.10+ 和 `openpyxl==3.1.5`。
- Node.js 与 Codex 捆绑的 `@oai/artifact-tool`，用于导出 Excel。

仓库不包含运行时、node_modules、客户真实数据或日常运行结果。运行入口会尝试发现本机 Codex 捆绑依赖；其他环境需要自行提供对应依赖。只安装 Python 依赖不能完成 Excel 导出，静态 PDF 和 Excel 则可直接查看。

## 使用 Skill

在 Codex 中读取本仓库内的 [SKILL.md](ecommerce-reconcile/SKILL.md)，按 [字段规范](ecommerce-reconcile/references/输入格式与口径.md) 提供四表并说明核对截止日。

Windows 本地演示：

```powershell
.\run.ps1 -Demo -OpenResult
```

也可双击 `一键演示.cmd`。每次输出到新的 `运行结果/` 子目录。

真实数据核对：

```powershell
.\run.ps1 -InputDir 'D:/商家数据/某批次' -AsOf '2026-09-19'
```

输出目录必须与输入目录分开。禁止用真实账目覆盖仓库中的模拟数据。商家修正来源的新副本后，应重新运行，不直接修改报表。

## 测试

默认测试使用仓库内已保存的模拟输入及演示快照，不重新生成演示。

```powershell
.\run.ps1 -Test
```

也可仅安装 Python 读取依赖后执行测试：

```text

```

覆盖重复订单/退款/费用、空金额、缺成本、超额退款、成本冲回、长编号、币种、日期、公式输入和金额精度等 50 组场景，以及文件哈希与防覆盖检查。

## 口径与边界

订单经营贡献 = 实收 - 成功退款 - 平台费用 - 商品成本 - 履约成本 + 明确提供的成本冲回。

“完整”仅说明上传的四表通过当前规则，不能证明没有漏交交易。尚未包含税费、人工、租金、广告等分摊，不是会计净利润或银行到账核对。当前不支持通用平台导出、SKU 拆单、多币种或负数费用冲销。没有登录、支付、会员和网站。
